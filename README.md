# 生活記帳簿（Life Ledger）

一個單一 HTML 檔就能跑的記帳工具，主打「拍一張發票就入帳」。
不需要伺服器、不需要資料庫、不需要安裝任何東西。

線上使用：https://yydsyyds1234.github.io/life-ledger/

## 功能

- **記一筆**：日期、類別、金額、備註，含輸入驗證，日期預設今天
- **發票／收據自動入帳**
  - 電子發票證明聯：掃 QR（依財政部 77 碼規格解析，取得字軌、開立日期、含稅總額、賣方統編）
  - 財政部寄來的電子發票 PDF：用 pdf.js 轉成影像後同樣掃 QR
  - 紙本收據：Tesseract.js 正體中文 OCR，從「總計／合計／應付」抓金額
  - 都失敗時：可手動輸入字軌號碼＋開立日期
  - 一律產生待確認草稿，人工核對後才寫入
- **防呆**：同一張發票號碼不會重複入帳；店家（賣方統編）會記住分類
- **統計**：總支出、筆數、平均單筆、最花錢類別、類別佔比長條圖
- **篩選**：月份、類別、關鍵字，三者可疊加
- **備份**：匯出 CSV（Excel 可開）與 TXT

## 使用方式

直接用瀏覽器打開 `index.html` 即可，或使用上面的線上網址。
資料存在瀏覽器 `localStorage`，不會上傳到任何伺服器；換裝置請先匯出 CSV／TXT。

## 技術

- 單檔自包含：HTML、CSS、內嵌 JavaScript，無框架、無建置流程
- QR 解碼：原生 `BarcodeDetector`，不支援時用 `jsQR`（CDN）
- PDF：`pdfjs-dist` 3.11（CDN）
- OCR：`Tesseract.js` 5（CDN，正體中文模型）
- 沒有後端，所以「載具（手機條碼）自動匯入」需另建後端＋財政部 API 憑證，本專案未實作
