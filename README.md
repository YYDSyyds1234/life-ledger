# 生活記帳簿（Life Ledger）

一個單一 HTML 檔就能跑的記帳工具，主打「拍一張發票就入帳」。
不需要伺服器、不需要資料庫、不需要安裝任何東西。

線上使用：https://yydsyyds1234.github.io/life-ledger/

## 功能

- **多帳本（記事本式）**：右上角帳本按鈕進「我的帳本」書架頁，日常／旅遊／公司報帳各開一本
  - 每本帳各自擁有紀錄、類別、預算、常用一鍵與店家記憶
  - 統計可切「本帳」或「全部帳本」；封存的帳不列入全部統計
  - 跨帳本搬移（勾選整批搬）、複製帳本、封存、刪除（上限 20 本）
  - 舊版單一帳本的資料會自動歸到「我的日常帳」，並提示是否分類
- **記一筆**：日期、類別、金額、備註，含輸入驗證，日期預設今天
- **發票／收據自動入帳**
  - 電子發票證明聯：掃 QR（依財政部 77 碼規格解析，取得字軌、開立日期、含稅總額、賣方統編）
  - 財政部寄來的電子發票 PDF：用 pdf.js 轉成影像後同樣掃 QR
  - 紙本收據：Tesseract.js 正體中文 OCR，從「總計／合計／應付」抓金額
  - 都失敗時：可手動輸入字軌號碼＋開立日期
  - 一律產生待確認草稿，人工核對後才寫入
- **防呆**：同一張發票號碼不會重複入帳；店家（賣方統編）會記住分類
- **統計**：總支出、筆數、平均單筆、最花錢類別、類別佔比長條圖
- **本月預算**：總預算＋分類預算，80% 轉黃、100% 轉紅，跨門檻才提示一次
- **常用一鍵**：把早餐、公車這種重複項目存成常用，點一下就入帳（右鍵移除）
- **六個月趨勢**：近 6 個月支出折線圖＋本月與上月增減比較
- **篩選**：月份、類別、關鍵字，三者可疊加
- **備份**：CSV（Excel 可開）、TXT、完整 JSON（多本帳＋類別記憶＋預算設定）可還原；久未備份會提醒

## 手機版（≤560px 自動切換）

手機打開時版面會重排，主要動作都在第一屏：

- 「記一筆」表單排到最前面，打開就能填
- 右下角固定「＋」浮動鈕，點開是底部面板：金額 → 常用類別 → 日期／備註 → 送出，三步記完
- 明細改成卡片（類別＋金額、備註、日期＋編輯/刪除），一次先列 8 筆，按「顯示更多」再 +8
- 預算、六個月趨勢、類別佔比收進「詳細統計」，需要時再展開
- 發票／收據區預設收起，按「展開」才顯示
- 匯出 CSV／TXT、備份、還原收進標頭右上角的「⋯」
- 作品說明搬到獨立「關於」頁（`#/about`），從頁尾或書架頁進入

實測（500px 寬、14 筆紀錄）：頁面總高度從約 5,880px 降到約 2,470px。

## 資料結構

`localStorage` 分成三層，改版時不會互相拖累：

| key | 內容 |
| --- | --- |
| `life-ledger-books-v2` | 帳本清單（名稱、類型、備註、封存狀態） |
| `life-ledger-books-data-v2` | 各本帳的紀錄、店家記憶、預算與常用 |
| `life-ledger-cur-book-v2` | 上次開啟的帳本 |
| `life-ledger-prefs-v1` | 統計範圍、提示狀態 |
| `life-ledger-v1` 等舊 key | 僅用於首次匯入舊資料，不刪除 |

## 使用方式

直接用瀏覽器打開 `index.html` 即可，或使用上面的線上網址。
資料存在瀏覽器 `localStorage`，不會上傳到任何伺服器；換裝置請先匯出 CSV／TXT。

## 技術

- 單檔自包含：HTML、CSS、內嵌 JavaScript，無框架、無建置流程
- QR 解碼：原生 `BarcodeDetector`，不支援時用 `jsQR`（CDN）
- PDF：`pdfjs-dist` 3.11（CDN）
- OCR：`Tesseract.js` 5（CDN，正體中文模型）
- 沒有後端，所以「載具（手機條碼）自動匯入」需另建後端＋財政部 API 憑證，本專案未實作
