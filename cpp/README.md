# 生活記帳簿 — C++／Dev-C++ 版

`LifeLedger.cpp` 是「生活記帳小助手」的命令列版本：單一 .cpp、無外部函式庫、不需要資料庫，資料存在同資料夾的 `ledger_data.txt`。

## 在 Dev-C++ 編譯

1. 開啟 Dev-C++ → `檔案 → 開啟專案或檔案` → 選 `LifeLedger.cpp`
2. 直接按 `F11`（編譯並執行），預設設定即可，不必改編譯器選項
3. 若主控台中文變亂碼，兩種解法任選：
   - 用 Windows 10/11 內建的「終端機」開啟 `LifeLedger.exe`
   - 或在 Dev-C++ 的 `工具 → 編譯器選項` 額外加 `-fexec-charset=big5`

程式碼只用 C++98 標準（`std::string`、`std::vector`、`iostream`），舊版 Dev-C++ 4.9.2 的 g++ 也能通過，已實測 `-std=c++98 -Wall -Wextra` 零警告。

## 功能

| 選單 | 功能 |
| --- | --- |
| 1 | 記一筆：日期（Enter=今天）、類別、金額、備註，含格式驗證 |
| 2 | 看紀錄：全部／月份／類別／關鍵字／條件疊加，15 筆一頁 |
| 3 | 編輯／刪除：日期、類別、金額、備註都可改，刪除前二次確認 |
| 4 | 統計：總支出、筆數、平均、最花錢類別、分類佔比長條 |
| 5 | 預算：總預算＋分類預算，80%／100% 各提示一次 |
| 6 | 匯出 CSV（UTF-8 BOM，Excel 直接開） |
| 7 | 帳本管理：切換、新增、改名、刪除（上限 20 本） |
| 8 | 搜尋 |
| 9 | 備份：複製成 `ledger_backup_YYYYMMDD.txt` |

資料檔格式（純文字，可自行編輯或備份）：

```
BOOK|帳本名稱|類型|總預算|分類預算0..8
REC|日期|類別索引|金額|備註
```
